# Prismflow

**Небольшой читаемый скриптовый язык вокруг потоков — без `if`, `while` и `for`.**

[Песочница](https://polka-we.github.io/prismflow/) · [Учебник](docs/tutorial.ru.md) · [English](README.md)

```
users = [[name: "Аня", age: 20], [name: "Боря", age: 15], [name: "Вера", age: 31]]
users where .age > 17 select .name :: print      // Аня, Вера
```

**[Онлайн-песочница](https://polka-we.github.io/prismflow/)** работает целиком в браузере (один файл
`docs/index.html`), с готовыми примерами на русском и английском.

## В чём уникальность

- **Нет операторов управления.** Ветвление — выражение `is`, повторение — `::` («для каждого элемента потока»).
  Есть `next`, `stop` и ранний `return`, поэтому BFS, Дейкстра и решето пишутся коротко.
- **Потоки везде:** `range(1, 10).map(f).filter(g)::print`, в том числе бесконечные.
- **Слова вместо скобок:** `where`, `select`, дырки `_`, UFCS (`x.f(a)` = `f(x, a)`); метод можно передать как функцию: `.map(split)`.
- **Точные числа:** длинные целые и точные десятичные `0.1d + 0.2d == 0.3d`.
- **Ошибки — значения:** `10 / 0 ?? "запасное"`.
- `=` — константа, `:=` — переменная; динамическая типизация, блоки по отступам, объекты `[k: v]`.
- **Два движка, одно поведение:** ядро на C99 (встраиваемое, работает на Android/Termux) и JavaScript (песочница), сверяются 700+ общими тестами.
- Подсказки «возможно, вы имели в виду …».

## Запуск

```sh
cd c && make
./prism ../examples/fizzbuzz.pr
bash tests/run.sh
```

Нужен только компилятор C99 и pthreads. JS-версия: `sh web/mk_engine.sh`, затем `node web/run.js файл.pr`.

Встраивание в C — см. [README.md](README.md#embedding-in-c) и `c/include/prism.h`. Доступ к файлам и HTTP по умолчанию выключен ([SECURITY.md](SECURITY.md)).

## Скорость

Интерпретатор без JIT: примерно между Lua без JIT и CPython. Выбор алгоритма важнее микро-оптимизаций (решето в учебнике).

## Структура

`c/` — ядро и тесты, `web/` — JS-движок и исходники песочницы, `docs/` — собранная песочница и учебники, `examples/` — примеры.
