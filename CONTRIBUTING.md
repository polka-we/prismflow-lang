# Contributing

Prismflow has two engines that must behave identically.

1. Change the C core in `c/src/parts/*.c` (then run `sh c/tools/amalgamate.sh` to regenerate `c/src/prism.c`, and `c/tools/gen_prelude.sh` if you touched `c/lib/prelude.pr`).
2. Mirror the change in `web/p*.js`, run `web/mk_engine.sh`.
3. Add a test pair `c/tests/parity/name.pr` + `name.expected` (generated by the C binary, reviewed by you).
4. Run `cd c && bash tests/run.sh` and `sh web/tests/parity.sh` — both must pass.
5. Rebuild the playground: `cd web && node build.js` and commit `docs/index.html`.

Bug reports: include the smallest program that shows the problem and the output of both engines.
