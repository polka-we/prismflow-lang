Переменные
x = 5        // константа
y := 5       // изменяемая
y += 1       // только для :=
arr += 6     // добавить в конец
arr -= 2     // убрать 2 с конца
arr - 1      // новый массив без последнего
arr + 9      // новый массив с 9 в конце
arr.remove(0) // убрать по индексу
arr.pop()     // убрать и вернуть последний
arr.pop(1)    // убрать и вернуть по индексу
b := arr.copy() // независимая копия
c := arr.dcopy() // глубокая копия
d := arr        // ссылка: оба имени меняют один массив
Блоки пишутся отступами, фигурных скобок в языке нет. Типы: int, float, string, bool, none, массив, объект, error. Массивы и объекты передаются по ссылке; b = a для изменяемого a — ошибка: пишите b := a или b = a.copy().

      
Числа
5       // int (любой размер)
5.0     // float
7 / 2   // 3.5: / всегда float
div(7, 2) // 3: целое деление
int(3.9) float(2) "12".to_int()
"1.5".to_float()
a[2.0]  // ошибка: индекс — int
is number подходит обоим типам, is int и is float — каждому.

      
is-выражение и when
s = is n > 9 -> "много" else -> "мало"
g = is n > 90 -> "A"
    is n > 80 -> "B"
    else -> "C"
is ready -> start()      // else можно опустить
job = print:("готово")   // отложенный вызов
job()
print:(a[i]) when i < n  // колбэк без аргументов
Строки is подряд — одна цепочка: срабатывает первая подходящая. Аргументы f:(…) вычисляются сразу, но при when — только если условие истинно.

      
Поток управления без while
range(10)::i
    is i % 2 == 0 -> next   // пропустить элемент
    is i > 7 -> stop        // закончить цикл
    print(i)
find x =                    // ранний return
    xs::y
        is y > x -> return y
    none
queue:: v                   // рабочий список: видит дописанное
    queue += v + 1
a, b := b, a                // множественное присваивание
next/stop работают в телах :: и в стадиях map/filter/flat_map. return в ветке is/match выходит из всей функции. Голое имя метода работает как функция: .map(split).

Функции
sum a b = a + b         // выражение
sum(a, b) = a + b       // со скобками
greet name =            // "=" в конце строки и тело с отступом
    print(name)
fact 0 = 1              // по случаям
fact < 0 = none         // условие на аргумент: < > <= >= == != %
fact n = n * fact(n - 1)
// общий случай можно записать и через _ : fact = _ * ...
f([a, b]) = a + b       // шаблон в скобках
f([age:, name:]) = name // шаблон объекта
inc = _ + 1             // безымянная: _ , _1 , _2
twice(_ * 2, 5)         // _ в аргументе вызова
add(1, _)               // голый _ - частичный вызов
Параметры названы в заголовке или это «дырки» _. Одиночный _ - один и тот же аргумент, для нескольких _1, _2. В аргументе метода (.map(_ * 2)), в теле :: и в правой части x = ... дырки образуют функцию. Лямбда в одну строку: x -> x + 1. Заголовок без параметров: имя = и тело ниже. Если в теле есть _, это функция (k = _ называет параметр k), иначе - значение блока. Блочная функция (заголовок кончается на =) возвращает значение последнего выражения в теле либо то, что указано в return; если последняя строка - присваивание, результат none. Старые fn и @имя пока работают.

      
Диапазоны и перебор
range(5)::print          // 0..4
range(1, 10, 3)::print  // 1 4 7
range(10, 0, -1)        // 10..1
5 in range(1, 10)       // true
0 <= x < 10            // цепочка
s[1..4] s[..3] s[-3..]  // срезы
arr::i,x -> print(i, x)  // индекс и значение
obj::k,v -> print(k, v)  // ключ и значение
users::u -> print(u)     // имя элемента
users::u                // или строка «::u» и тело с отступом
    print(u)
range(начало, конец, шаг): конец не включается, начало по умолчанию 0. Срез [от..до]: минус считает с конца.

      
Типы и методы
type Point [x, y]
type User [name, age = 18]
p = Point(1, 2)
p is Point               // true
area(Circle c) = 3 * c.r ** 2
area(Rect [w:, h:]) = w * h
p.dist(q)                // то же, что dist(p, q)
5.double()               // метод для int
move(Point p, d) =
    p.x += d
q := Point(0, 0)
q.move(1)                // можно: q из :=
Метод - обычная функция, тип первого параметра выбирает случай. p.f(a) вызывает f(p, a). Функция меняет массив или объект только если ей передали изменяемую переменную (:=); константа (=) защищена. Копия - .copy(), глубокая - .dcopy().

      
match
x match
    is % 2 == 0 -> print("чётное")
    is x > 100 ->
        print("много")   // ветка-блок
    is [age: 18] -> print("18")
    is [a, ...rest] -> print(a)
    is error -> print("ошибка")
    else -> none
else обязателен. Условие должно быть bool.

where и select
users where .age > 17 select .name :: print
adults = users where _.age > 17
names = users
    where .age > 17
    select .name
where — фильтр, select — преобразование. Ведущая .имя значит _.имя, а ["имя"] — _["имя"] (то же поле: obj.x и obj["x"] равны). Слова ниже по приоритету, чем and/or; пишутся после выражения, поэтому слева стоит целое выражение. Те же действия: .filter(…) и .map(…).

Переносы строк
range(10)
    .filter(i -> i > 3)
    ::i
        print(i)
Блок открывает строка, которая кончается на = (заголовок функции), ->, :: (с именами или без) или match; тело пишется с бо́льшим отступом. Перенос внутри скобок не важен. Продолжением выражения считаются строки, которые начинаются с ., ::, where, select или оператора. Старый синтаксис со скобками {}: первая строка // syntax: v1.

      
Время и ожидание
time.wait(500)        // пауза в мс: программы или функции
f() =                 // тело с time.wait ждёт только f
    time.wait(100)
job = f()             // вызов вернул задачу сразу
await job             // дождаться и получить результат
await [a, b]          // дождаться всех
time.program()        // мс с начала программы (float)
time.time()           // местное время устройства
time.world()          // мировое время UTC+0
t.year t.month t.day t.hour t.minute t.second t.ms t.unix t.text
time.test(fn, 100)    // среднее время fn в мс
time.test(fn)         // один повтор
await не к задаче возвращает значение как есть. Тело :: с time.wait идёт по очереди; xs::имя запускает функцию параллельно для каждого элемента.

Variables
x = 5        // constant
y := 5       // mutable
y += 1       // only for :=
arr += 6     // append
arr -= 2     // remove 2 from the end
arr - 1      // new array without the last item
arr + 9      // new array with 9 appended
arr.remove(0) // remove by index
arr.pop()     // remove and return the last
arr.pop(1)    // remove and return by index
b := arr.copy() // independent copy
c := arr.dcopy() // deep copy
d := arr        // reference: both names change one array
Blocks are written with indentation, there are no curly braces. Types: int, float, string, bool, none, array, object, error. Arrays and objects are passed by reference; b = a for a mutable a is an error: write b := a or b = a.copy().

      
Numbers
5       // int (any size)
5.0     // float
7 / 2   // 3.5: / is always float
div(7, 2) // 3: integer division
int(3.9) float(2) "12".to_int()
"1.5".to_float()
0.1d + 0.2d == 0.3d  // exact decimals
precision(30)        // all fractions exact
a[2.0]  // error: an index must be int
is number matches both types, is int and is float match one each.

      
is expression and when
s = is n > 9 -> "many" else -> "few"
g = is n > 90 -> "A"
    is n > 80 -> "B"
    else -> "C"
is ready -> start()      // else may be omitted
job = print:("done")     // deferred call
job()
print:(a[i]) when i < n  // callback without arguments
Consecutive is lines form one chain: the first match wins. Arguments of f:(…) are evaluated at once, but with when only if the condition is true.

      
Control flow without while
range(10)::i
    is i % 2 == 0 -> next   // skip this item
    is i > 7 -> stop        // end the loop
    print(i)
find x =                    // early return
    xs::y
        is y > x -> return y
    none
queue:: v                   // worklist: sees appended items
    queue += v + 1
a, b := b, a                // multiple assignment
next/stop work in :: bodies and in map/filter/flat_map stages. return inside an is/match branch leaves the whole function. Bare method names work as functions: .map(split).

t[0].age   // 18

Functions
sum a b = a + b         // expression
sum(a, b) = a + b       // with parentheses
greet name =            // "=" at the end of the line and an indented body
    print(name)
fact 0 = 1              // by cases
fact < 0 = none         // argument condition: < > <= >= == != %
fact n = n * fact(n - 1)
// the general case can also use _ : fact = _ * ...
f([a, b]) = a + b       // pattern in parentheses
f([age:, name:]) = name // object pattern
inc = _ + 1             // anonymous: _ , _1 , _2
twice(_ * 2, 5)         // _ in a call argument
add(1, _)               // a bare _ is a partial call
Parameters are named in the header or are _ "holes". A single _ is one and the same argument; use _1, _2 for several. In a method argument (.map(_ * 2)), in a :: body and on the right of x = ... the holes make a function. One-line lambda: x -> x + 1. A header without parameters: name = and a body below. If the body has _ it is a function (k = _ names the parameter k), otherwise it is a block value. A block function (header ends with =) returns the value of its last expression or what return says; if the last line is an assignment, it returns none.

      
Ranges and iteration
range(5)::print          // 0..4
range(1, 10, 3)::print  // 1 4 7
range(10, 0, -1)        // 10..1
5 in range(1, 10)       // true
0 <= x < 10            // chained comparison
s[1..4] s[..3] s[-3..]  // slices
arr::i,x -> print(i, x)  // index and value
obj::k,v -> print(k, v)  // key and value
users::u -> print(u)     // name of the item
users::u                // or a "::u" line and an indented body
    print(u)
range(start, end, step): the end is excluded, start defaults to 0. Slice [from..to]: a minus counts from the end.

      
Types and methods
type Point [x, y]
type User [name, age = 18]
p = Point(1, 2)
p is Point               // true
area(Circle c) = 3 * c.r ** 2
area(Rect [w:, h:]) = w * h
p.dist(q)                // same as dist(p, q)
5.double()               // a method for int

A method is an ordinary function; the type of the first parameter selects the case. p.f(a) calls f(p, a). A function changes an array or object only if it is passed a mutable variable (:=); a constant (=) is protected. Copy with .copy(), deep copy with .dcopy().

      
match
x match
    is % 2 == 0 -> print("even")
    is x > 100 ->
        print("big")     // block branch
    is [age: 18] -> print("18")
    is [a, ...rest] -> print(a)
    is error -> print("error")
    else -> none
else is required. The condition must be bool.

      
Streams
range(5)::print

f.from(1).take(5)
f.from(1).take_while(_ < 9)

A stream is lazy. A statement-level stream runs to the end; if the last expression of a block is a stream, it is returned as the block value. Chains over arrays run element by element.

where and select

where filters, select transforms. A leading .name means _.name, and ["name"] means _["name"] (the same field: obj.x equals obj["x"]). The words bind more loosely than and/or; they follow an expression, so the left side is a whole expression. Same as .filter(…) and .map(…).

Line breaks
range(10)
    .filter(i -> i > 3)
    ::i
        print(i)
A block is opened by a line that ends with = (function header), ->, :: (with or without names) or match; the body is indented deeper. Line breaks inside brackets do not matter. Lines that start with ., ::, where, select or an operator continue the expression. Old brace syntax: put // syntax: v1 on the first line.

      
Time and waiting
time.wait(500)        // pause in ms: the program or a function
f() =                 // a body with time.wait waits only f
    time.wait(100)
job = f()             // the call returned a task at once
await job             // wait and get the result
await [a, b]          // wait for all
time.program()        // ms since program start (float)
time.time()           // the device's local time
time.world()          // world time UTC+0
t.year t.month t.day t.hour t.minute t.second t.ms t.unix t.text
time.test(fn, 100)    // average time of fn in ms
time.test(fn)         // a single run
await on a non-task returns the value as is. A :: body with time.wait runs in sequence; xs::name starts the function in parallel for each item.
